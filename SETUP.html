🚀 Cara Membuka Website

Opsi 1: Buka Langsung di Browser

Klik dua kali file index.html atau drag ke browser

Opsi 2: Gunakan Live Server (Recommended)

Jika menggunakan VS Code:

  1. Install extension "Live Server"
  2. Klik kanan pada index.html
  3. Pilih "Open with Live Server"

Opsi 3: Python Simple Server

Buka terminal di folder project, lalu jalankan:

python3 -m http.server 8000

Kemudian buka: http://localhost:8000

💡 Tips: Gunakan Live Server agar perubahan langsung terlihat saat Anda refresh browser

📝 File-file yang Ada

  • index.html - File utama website
  • styles.css - Semua styling dan design
  • script.js - Interaktivitas dan animasi
  • README.md - Dokumentasi lengkap
  • package.json - Metadata project
  • .gitignore - Untuk Git repository

🎨 Cara Mengustomisasi

1. Ubah Nama & Data Pribadi

Buka index.html dan cari bagian berikut, lalu ubah sesuai data Anda:

<h1 class="hero-title">Adhim Satya Nugraha</h1>
<p class="hero-subtitle">UI/UX Designer | Full Stack Developer | Creative Developer</p>

2. Ubah Warna (Color Scheme)

Buka styles.css dan ubah di bagian :root:

:root {
    --primary: #6366f1;      /* Warna utama */
    --secondary: #8b5cf6;    /* Warna sekunder */
    --accent: #ec4899;       /* Warna aksen */
}

3. Tambah Project Portfolio

Cari section <div class="portfolio-grid"> di index.html dan tambahkan:

<div class="portfolio-item" data-category="web">
    <div class="portfolio-image">
        <img src="image-url.jpg" alt="Project Name">
    </div>
    <div class="portfolio-content">
        <h3>Nama Project</h3>
        <p>Deskripsi project</p>
        <div class="tech-stack">
            <span>Technology</span>
        </div>
    </div>
</div>

4. Tambah Social Media

Cari bagian .social-links dan update dengan link sosial media Anda

🌐 Deployment (Upload ke Internet)

Opsi 1: Netlify (Recommended - Gratis)

  1. Buka netlify.com
  2. Klik "Deploy manually" atau "New site"
  3. Drag folder project ke area upload
  4. Website live dalam hitungan detik!

Opsi 2: Vercel (Gratis)

  1. Buka vercel.com
  2. Koneksi dengan GitHub
  3. Pilih repository portfolio
  4. Deploy dengan satu klik

Opsi 3: GitHub Pages (Gratis)

  1. Buat repository dengan nama username.github.io
  2. Push semua file ke repository
  3. Akses via https://username.github.io
✅ Tips: Semua opsi di atas gratis dan mudah! Pilih yang paling nyaman untuk Anda.

🔧 Troubleshooting

❓ Gambar tidak muncul

Replace SVG placeholder dengan image URL yang valid. Atau upload gambar ke folder dan reference dengan path relatif.

❓ Animasi tidak smooth

Refresh browser (Ctrl+F5 atau Cmd+Shift+R). Jika masih tidak smooth, check Developer Console untuk errors.

❓ Mobile menu tidak bekerja

Buka DevTools (F12), cek Console tab untuk error messages. Pastikan script.js ter-load dengan baik.
